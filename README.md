# Samsung Supply Chain Analytics Project

# Business Problem
Supply chain operations generate large amounts of inventory, fulfillment, supplier, and logistics data. The objective of this project is to analyze operational performance and identify opportunities for inventory optimization and supply chain efficiency.

# Project Objectives
-Monitor inventory performance
-Analyze order fulfillment trends
-Evaluate supplier performance
-Track logistics KPIs
-Generate data-driven business insights

# Tools Used

  •	Power BI
  •	Excel
  •	Python
  •	GitHub

# Key Insights
•	Identified top-performing product categories.
•	Analyzed inventory distribution across products.
•	Evaluated shipping performance by carrier.
•	Examined supplier quality using defect rates.
•	Built KPI tracking for supply chain monitoring.

# Recommendations
•	Increase safety stock for fast-moving products.
•	Review supplier quality issues.
•	Optimize logistics routes.
